# TechConnect

TechConnect is a modern technology community platform for students, developers, and professionals to ask questions, share solutions, and build meaningful connections.

## Stack
- Next.js 14
- React 18
- TypeScript
- Tailwind CSS
- Supabase-ready data model and auth flow

## Getting started

```bash
npm install
npm run dev
```

Then open http://localhost:3000.

## MVP included
- Landing page and community discovery pages
- Explore filters and search
- Discussion detail with accepted solution UI
- Create discussion page
- Community directory and profile view
- Notifications and auth experience
- Responsive dark theme inspired by community platforms

## Supabase-ready notes
This MVP is structured to be replaced with real Supabase Auth, database tables, and realtime subscriptions. The UI and data layer are separated so you can connect the project to database-backed models without reworking the marketing and community experience.
